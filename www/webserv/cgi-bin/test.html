CGI Script Tester

Run the CGI scripts in /cgi-bin with GET or POST and inspect the raw output.

GET requests

easy_script.py easy_script.py?query script.pl error_script.py (500) infinite_loop.py (timeout)

Python runs via /usr/bin/python3, Perl via /usr/bin/perl — both registered in the /cgi-bin location.

GET hello.py

Sends your name as a query string — the script replies with Hello.

POST to easy_script.py

Sends application/x-www-form-urlencoded data to the Python CGI script. The script echoes the request body.

POST to script.pl

Same data sent to the Perl CGI script (requires Perl registered in the config).
